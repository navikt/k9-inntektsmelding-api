# k9-inntektsmelding-api

Innsendingsapi for inntektsmelding for pleiepenger, omsorgspenger og opplæringspenger.

Dette prosjektet inneholder et REST API for innsending av inntektsmeldinger til pleiepenger, omsorgspenger og opplæringspenger 
som skal benyttes av Lønns- og personalsystemer (LPS). Løsningen skal muliggjøre uthenting av data for forespurte og innsendte inntektsmeldinger av en
organisasjon.
